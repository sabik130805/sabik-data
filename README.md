# Premium IPE Portfolio Theme

Files:
- index.html
- style.css
- script.js

How to use:
1. Open index.html in any modern browser.
2. Replace "Your Name", email, social links, and project content.
3. Replace the photo placeholder with your image if desired.
4. Add your CV file and update the Download CV link.
5. Deploy to GitHub Pages, Netlify, Vercel, or any static host.

Theme:
- Responsive
- No framework required
- Smooth scroll and reveal animations
- Premium glassmorphism + editorial layout
- IPE-focused skills/projects
